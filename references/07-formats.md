# 07 · 七种爆款形态速查

参考片和目标片会命中这些形态，可混合。每种形态只给"决定成败的关系"；具体导演仍走六阶段。

## 1. 口播 talking-head（一人对镜）

- **核心关系**：一个人直接对镜头表达，靠这个人的判断、语言和人格魅力。
- **资产**：一张被认可的人物场景图（主 A-roll）+ 一个固定音色贯穿全片。
- **要点**：动作要有表达目的（不是乱动），停顿处自然跳剪；同一个机位下靠表情、停顿、手势、切 B-roll 维持紧迫。
- **陷阱**：把口播当朗读，没态度；或一堆花字盖过了人。

## 2. 盘点排行 ranking/listicle

- **核心关系**：**榜单状态本身讲故事**——片头已有预置项，随叙事逐步激活/揭晓，状态的累积与变化制造期待。
- **资产**：人物偏侧构图，为榜单留出干净区域；榜单/图标是可编辑图形系统，不烧进画面。
- **要点**：图标承担信息角色（每个名次一个可识别身份）；人评说、榜单更新，二者交替推进；揭晓跨"花字状态 + 音效 + 闪色"一次完成。
- **陷阱**：榜单只是个背景装饰、没有"状态变化"；或每个名次平均用力，没有悬念与排序理由。

## 3. 短剧 short-drama

- **核心关系**：表演驱动，每段一个戏剧任务（一个目标、一个阻碍、一次推进），观众为角色处境追下去。
- **资产**：建立角色（多人各自身份）、双人/共享世界的场景图（能派生双方机位），背景承载故事（发生在具体生活里，不是空背景）。
- **要点**：表演要带因果（前一个动作引发下一个反应）；台词自然、情绪推进；镜头切给此刻重要的人。
- **陷阱**：只有"情景"没有戏剧冲突；或用解说代替表演；AI 表演夸张、动作像在执行清单。

## 4. 街头采访 street-interview

- **核心关系**：采访者走进一个有自己生活的人，问出一个值得看的答案。**受访者承载故事，采访者帮观众发现它**。
- **三视图法**：先生成一张**双人同框的共享场景图**（真实空间关系），再从它派生受访者近景和采访者近景（采访者镜头保留对方一点边缘，保证交流可读）；视线沿同一屏幕轴线。
- **要点**：给相遇"前与后"（开场受访者在忙自己的事，结尾自然抽身离开），暗示镜头外有生活；镜头切给此刻说话/重要的人，而非定时正反打。
- **揭示**：一个答案的揭晓可同时更新 emoji 条一格 + 一个短音效 + 一次闪色，复用同一个 Moment；其余答案保持、未答的留问号。
- **陷阱**：强行夸张反应、两个人都像在表演；编造采访者和受访者之间的运镜移动。

## 5. 双人播客/对谈 two-person-podcast

- **核心关系**：两人的关系承载论证——提问引出主张、反应改变含义、回应完成兑现。
- **资产**：先生成主主持人在场景中的图，再派生**互补机位**（屏幕位置相反、视线相反、麦克风从另一侧入、露出同一场景的另一角）；产品在两人手中"手递手"要归属清晰。
- **要点**：沉默者也要"活着"（一个坐姿调整、低头再抬眼）；一个 Segment 可含多轮对话与切镜；可做上下分屏开场，一眼交代两人。
- **B-roll**：可以一条无声蒙太奇跨多个例子，不必每个名词配一张图；给它完整演完的时间。
- **陷阱**：产品在两人手里"瞬移"、谁拿着说不清；两人各说各的、没有反应关系。

## 6. 讲解演示 presenter-led-explainer

- **核心关系**：**口语与演示/图形共同论证**，人物在镜的表演与"呈现的东西"各自独立又互相配合。全屏、小窗、覆盖只是外观，不是结构。
- **要点**：每个事件、转场都要给足时间（操作过程、界面变化、结果）；人解释时，演示/界面/MG 同步给出证据；复杂结构用图形讲清，别只靠说。
- **资产**：产品/界面锚点图要精确（真实 UI 用参考图）；图形信息层可编辑。
- **陷阱**：屏幕内容一晃而过观众看不清；或人一直讲、演示在背景里没对上话。

## 7. 旁白带货/旁白演示 narration-led-demo

- **核心关系**：独立旁白（**audio-only A-roll**）是一条口语脊柱，画面围绕它设计多个"视觉回答"，而不是给可见口播打补丁。
- **关键判断**：是否依赖"镜头前的人在说"。独立旁白即使画面有手/产品，也属此类；有镜前人物只是偶尔被 B-roll 覆盖，仍属讲解型。
- **画面分类**：context（建立谁/在哪/演示什么）、proof（用使用/结果/对比让主张可见）、B-roll（具体动作/对象/情绪）、屏幕媒体（界面真实细节）、MG/Typography（结构/累积/转化/概念）。
- **要点**：建视觉证据而非名词插图；一个旁白者（一个音色）贯穿全片，即使有多个画面切换；每个需要画面的区间都有明确决定，不留空边。
- **字幕**：字幕仍是"说的话"；步骤、标签、数字、标题、CTA 是独立 Typography/MG，不要混为字幕。
- **陷阱**：照着旁白名词逐个配图，热闹但没有证明；画面区间出现空镜或继承的废片。

## 混合判断

- 一条片可同时用多形态（如"口播开场 + 盘点主体 + 旁白演示收尾"）。在 TREATMENT 里写清每段采用哪个形态、转场如何衔接。
- 形态决定**资产关系**（如街采要三视图、播客要互补机位、盘点要榜单系统），别用通用单人口播的素材法去套多人形态。

# 06 · 合成与审片

素材齐了，组装成片。合成分两层：**确定性剪辑**（拼接、转场、裁切、调速、字幕压制、混音、分屏）用适配层（00）的**剪辑工具**；**精细花字/头部追踪/逐帧 MG** 用**专业编辑器**（豆包环境 = 剪映专业版/jianying-editor 或即梦画布）。本篇给导演层的判断，不重复工具参数，具体工具名见适配层。

## 一、给每个素材一个"出现理由"（B-roll）

素材不是填满时间线，而是回答某段话：

- **证据**：现场、使用过程、结果、对比，让主张被看见。
- **场所/氛围**：让人物与世界可感。
- **动作/情绪**：一个反应、一个细节。
- 与思想的关系：要么**精确对应**（某个主张必须配某张图），要么**一段视觉思维跨多图**（一个习惯/过程/态度，用多图蒙太奇，不必每个名词配一张图）。
- 建"视觉证据"而非"名词插图"：讲快，就给一个快的动作；讲好用，就给使用与结果，不要给一堆与名词无关的通用图。
- 素材主导的蒙太奇（音乐卡点、工艺过程、产品特写）可以成为主序列，按视觉论证/动作/乐句选切点，不按解说词逐字配。

### 声画交接

- 素材可以"自带声音提前进入"（J-cut）：下一段说话者的声音先到，画面稍后才切；或画面先切、声音延续。
- 素材的出现与离开由"思想/动作/看清所需时间"决定，不绑死在说话者露脸与否。静态图停留到读清，动态素材让它把关键动作演完再切。
- 不要为了填满区间把素材循环/慢放/定格；留不住就明确回到主画面或黑场。

## 二、字幕（Caption）

字幕显示正在说的话，**与话语的同步关系最重要**。它不是装饰，也不是独立标题。

### 分组（Cue）

- 一个 Cue 是一个计时话语块，不是一行。让一个 Cue 承载观众能边看画面边读完的连贯短语。
- 不可拆的保持一起：名字、否定、数量+单位、介词+宾语、动词短语、复合词、定语+宾语。
- 英文最小计时单位是**词**，中文是**单字**（中文可逐字高亮，一个 Cue 容纳字数可比英文词数多）。按意思、阅读时间、字体实际占宽决定，不设固定字数。
- 一个意群想整体强调（如"组件化""十九块九"），在脚本里标成整体，高亮覆盖从首字到末字。
- 强调与分组独立：同一时间轴可以整句常显、当前词/字变色、拖尾、卡拉OK。逐字 karaoke 适合快节奏口播，整句常显适合需要边看演示边读。

### 视觉语言

- 字体、字号、行高、描边、阴影、对比、运动**一起选**；在亮帧和暗帧上都要可读。
- 粗描边给 energetic 字幕形状，轻投影给安静处理；字号增大时注意中文字内部留白别糊。
- 不挡脸、不挡产品、不挡关键动作；头部追踪字幕要给整句预留头顶空间。
- 说话人可用不同颜色区分（双人/采访），但颜色与画面、图形协调，别每个系统一个色。
- 字幕（说的话）与花字（独立标题/标签/榜单）是两个系统，不要混做。

### 工具

- 标准字幕条/内嵌字幕：适配层的**字幕工具**（基于转写时间轴压制进画面）。
- 花字、emoji 条、头部追踪、逐字卡拉OK、复杂动画：**专业编辑器**（豆包环境 = 剪映/即梦画布），本技能产出样式方案（字体气质、位置、触发词、停留、配色），不假装剪辑工具能做像素级追踪。

## 三、声音混音

- **从素材已有的声音开始**：A-roll 人声本身带环境感；B-roll 可能自带门声、脚步、笑声，先听有什么，再决定加什么。
- 人声承载信息时，BGM/音效在**名字、数字、主张、punchline、安静反应**周围让位（压低或留白）；在停顿、动作段、音乐主导段再放开。
- 每个音效要有表达理由：一个揭示配一个精准音效，别每个切点都放同一种音效；小触点声比大撞击更显质感。
- 音效挂到它回答的语义锚点（Selection/Moment），跟着台词走；BGM 可独立占一段。
- 画面切不等于声音切：同一场景的房间音、跨画面的音乐保持连续；换场/换视角/换叙事才需要可听的交接。
- 工具：适配层的**混音工具**（人声+BGM+音效混合）、淡入淡出、音量调整、音频分离/合流。

## 四、图形与动效（Typography / MG / UI）

- **构图一个想法，不是堆装饰**：先定眼睛先看什么、什么支撑它、下一拍什么变。用大小、间距、分组、对比、颜色、运动表达层级。
- 素材与图形共处：生图时就预留图形区（见 05）；实拍里的招牌归场景，解释性标签归图形，分清。
- 精确事实放**可编辑结构**：排名、对比、进度、价格、数据卡，文字/数字/几何要可改、可对齐，不要烧进画面或让视频模型随机生成假字、假 Logo。
- **导演变化，而不只是入场**：榜单会累积答案、卡片可被拿起来又退回、对比会变化。一个漂亮入场救不了"稳定态没讲清主张"。
- 对象跨变化保持身份：卡片变附件保留形状/轨迹，界面换风格保留可识别控件，让观众看懂"什么变了"。
- 所有动效属于**一套视觉语言**：调色板、字体、描边、质感、深度、运动、声音统一；运动派生自它描绘的关系（指针移到它要按的按钮、标签跟着它标注的对象）。
- 出现数据/指标：写清起始值、结束值、单位、变化路径、每个中间状态的触发点与停留；没有真实来源就写"概念状态变化"，不编具体数字。
- 复杂 MG（逐帧图表、HTML 级动效、头部追踪）明确转**专业编辑器**（豆包环境 = 剪映/即梦画布/人工），本技能给分镜与逐拍状态描述。

## 五、物理组装顺序（剪辑工具参考，具体流程见适配层）

1. 按分镜**裁剪**取舍各段、**拼接**成序（需要转场在拼接处加）。
2. 分屏/对比用**空间拼接**（多画面组合）；画中画/覆盖走专业编辑器。
3. 需要**调速、裁切、滤镜、运镜**时按镜头逐个处理。
4. 独立配音：**去原声** → **合回配音**；**混音**叠 BGM/音效；淡入淡出处理首尾。
5. 标准**字幕**压制；花字/图形在专业编辑器完成。
6. 导出前在目标画幅、目标平台下完整看一遍。

## 六、审片：看实际成片，逐条对照

**没看过完整成片不能宣称完成。** 用实际编码后的文件，在交付尺寸下看：

- **表演**：片段里真有预期的台词、动作、反应吗？剪辑/图形动效不能替代素材里缺失的动作。
- **画面与覆盖**：B-roll 是否支撑该段，显示窗口是否覆盖该解释或交接。
- **语义时间**：切点、字幕块、图形状态、特效是否落在正确的词/停顿/事件；开场对了，不代表揭示落对了字。
- **共享布局**：一段布局在内容变化时是否仍连贯；交接处（前后都看）有没有一帧闪屏、空隙、错位。
- **字幕**：不同说话人/位置/颜色/强调是否可读、是否属于该话语、有没有挡脸挡产品。
- **花字与 UI**：独立文字层级、内容、停留、与画面关系是否正确。
- **构图**：每个元素是否有足够空间，全帧保持预期视觉层级。
- **几何三层**：读外框（Canvas）→ 中框（外框/背景）→ 内内容，逐层检查容纳、裁切、对齐。
- **声音**：人声在关键信息处是否清楚，音效是否挂对事件，BGM 是否保持整片气质。

### 换人/换产品时，按"功能"对比，不比对像素

参考的 ANALYSIS/TIMELINE 是问题地图：对比榜单累积、A-roll 转 B-roll、字幕换说话人、MG 揭示、收束呼应开场这些**关系**在新片里是否成立。目标有意改变的，以 TREATMENT 为准。

### 返工归属（改错地方会越改越乱）

| 问题 | 改哪里 |
| --- | --- |
| 故事/镜头逻辑/视觉系统错 | TREATMENT |
| 台词、说话人、字幕分组、语义锚点错 | SCRIPT |
| 构图、样式参数、时间关系错 | 合成工程 / 镜头提示词 |
| 选错文件、拼接顺序错 | 合成工程（不回改创意） |
| 某个素材演不出它的职责 | 重新生成该素材（见 05 返工） |

改一处后，看受影响区间及其交接，再放回整片判断；没变好就回到原因层，不要叠参数。成片在布局、可读性、节奏都清楚有力地承载 BRIEF/TREATMENT 时才交付，并说明做了哪些取舍与限制。

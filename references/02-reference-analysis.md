# 02 · 拆解参考视频（ANALYSIS + TIMELINE）

克隆的质量首先取决于你看懂了多少。拆两遍：**第一遍通读抓整片模型，第二遍做时间码级语义拆解**。

## 一、拿到素材

- 链接（抖音/B站/快手/YouTube 等）→ 用适配层（00）的**下载工具**保存为本地文件。
- 本地文件直接用。多条参考时分别建目录。
- 用适配层的**媒资工具**探测时长/分辨率/帧率/音轨；用**转写工具**做词级时间戳转写（中文平台显式指定 zh），存 `transcript.*`。
- 无台词或台词极少的作品，跳过转写，改用动作/场景变化定位（见后）。

## 二、第一遍：通读，建立整片模型（写 ANALYSIS.md）

正常速度完整看，不暂停，记录"作为观众的体验"：

1. **前 3 秒发生了什么**：你看到/听到什么，为什么没划走？（钩子类型：异常结果、强冲突、主动入场、悬念、反常识）
2. **论证如何推进**：它在让你相信什么？每一步靠什么说服——演示、对比、数据、故事、情绪、反转？
3. **注意力如何转移**：什么时候画面/声音/字幕切换把注意力拉到新东西上？
4. **收束与回报**：高潮/笑点/答案落在哪，怎么呼应开场？
5. **预期反应**：它希望观众看完有什么反应（笑、惊讶、被种草、转发）？
6. **整片形态**：属于口播/盘点/短剧/街采/双人播客/讲解/旁白中的哪类（可混合，见 07-formats）。
7. **一句话总结"它为什么有效"**：这是后面所有改编的锚。

ANALYSIS 写整片层面：形态、故事、反复出现的系统、系统间关系、为什么成立。**不在这一层记逐秒细节。**

## 三、第二遍：时间码级语义拆解（写 TIMELINE.md）

### 1. 抽帧 + 对齐

- 用适配层的**媒资工具**按固定间隔抽帧，再在画面突变/转场处加密抽帧；需要时把连续片段截出来。
- 把画面变化与转写的**词、停顿、语气**对齐：画面往往是在某个词说出口、某个停顿、某个答案出现时才切。
- 抽帧网格（grid）一次看多帧，便于看连续运动和交接。

### 2. 按功能给画面分层（关键，别只描述"画面里有什么"）

每个瞬间问"这一层在承担什么功能"：

- **A-roll**：承载语义的主表演——谁在说、做什么、表情动作。
- **B-roll**：证据/空镜/生活画面——为主张提供视觉证据或氛围。
- **Caption（字幕）**：显示正在说的话，与话语同步。
- **Typography（花字/独立文字）**：标题、标签、榜单、emoji 条、数字大字——不是台词，是独立信息层。
- **MG / UI**：动态图形、界面、图表、进度条、卡片、动画。
- **声音**：人声、环境音、BGM、音效；注意哪些声音在某句话周围让位、哪些音效卡在哪。

### 3. 持续对象是"系统"，只记录一次

- 一个贯穿多镜头的对象（榜单、人物、道具、屏幕、某条图形）是**同一个系统**：在 ANALYSIS 里描述一次它的身份与规则；在 TIMELINE 里只记它"在哪个时间点发生了什么变化"。
- 例：排行榜在片头已有预置项，第 12 秒新激活一个、第 24 秒又激活——系统只记一次，变化点记三次。

### 4. 观察与推断分开

- 一栏写**客观所见/所听**（字面台词、画面元素、切点、声音）；
- 一栏写**推断的功能**（"这里切 B-roll 是为了给上一句主张提供证据"）。
- 参考的原始秒数是证据，不是新片要照搬的时间。

### 5. 时间轴表格建议

```
| 源时间 | 阶段 | A-roll 表演 | B-roll/画面 | 字幕/花字 | MG/UI | 声音 | 功能（推断） |
| 00:00-00:03 | Hook | ... | ... | ... | ... | 音效卡在哪 | 为什么抓人 |
```

"阶段"用源时间 + 功能名（Hook/论证1/反转/收束），不必按镜头机械切。

### 6. 无台词作品

纯动作/音乐/演示类，用**动作变化、场景切换、音乐节拍、图形事件**作为时间轴锚点，记录"每个变化为观众提供了什么新信息或情绪"。

## 四、拆完的检查清单

- 能用一句话说出吸引力来源，且指得出它在时间轴上的具体位置。
- 每个反复出现的系统都有身份描述 + 变化点。
- 每个画面切换都能回答"为什么此刻切、切后新增了什么"。
- 每个花字/图形/音效都能对应到它服务的那句话或那个事件。
- 区分了"参考片独有的具体形式"与"跨改编也成立的功能关系"（后者是要继承的）。

## 五、多参考 / 混合

- 一条参考驱动整个结构时，以它为骨架；多条参考时，注明"镜头节奏取自 A、字幕风格取自 B、榜单玩法取自 C"，冲突在 TREATMENT 里解决，不要把所有表面细节混在一起。
- 参考片是竞品/真实品牌时，品牌、Logo、真人脸、原始文案只作为**结构与风格参考**，不进入新片画面与提示词（合规，见 05）。

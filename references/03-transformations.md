# 03 · 改编：换人 / 换产品 / 换语言

改编 = **先保住角色（role），再重塑形式（form）**。参考片里每个元素都在完成某个"工作"，改编要让新主体把同样的工作做完，但允许它用完全不同的具体形式。

## 一、改编前先列"全部出现形态"

替换任何对象前，先把它在片里**所有出现的地方**列全。只换最显眼的那张脸，会留下大量穿帮的旧身份。

### 主持人/人物的出现形态

- 头像与身体（A-roll 主画面）
- 声音（配音、旁白、空镜里的说话声）
- 反应/空镜里的人（B-roll、生活场景）
- 手机/屏幕/照片里出现的本人
- 图形系统里的身份（头像图标、姓名条、emoji 条、榜单上的形象）
- 别人对他的称呼、台词里的指代

### 产品的出现形态

- 手持/桌面的实物道具
- 屏幕/界面（App、网页、设备显示）
- 使用演示（动作过程、结果、对比）
- 功效主张（台词怎么说它）
- 包装/Logo/品牌色
- 结尾 CTA（"点链接""进店"）
- 价格/数据/优惠信息

每一种形态都要给出新主体的对应物，标注"有对应 / 需新造 / 该形态在新片里删除"。

## 二、保留目的，重造形式

- 保住动作、构图、呼应的**目的**，重造适合新主体的形式。
  - 原片靠"人类摊手"表达无奈，换成宠物可以用一个定格姿势、眼神、甩尾表达自信；换成无屏产品，可以用另一种证据演示同一卖点。
- 一个不再合适的形式不必照搬。换产品后，原来的"扫码演示"可以换成"当面试用"，只要它证明的是同一件事。
- 参考的幽默/视觉关系/节奏要保住，但要让新人物、新产品把它"演活"，而不是贴在表面。

## 三、七个改编镜头（逐个过，不要漏）

1. **主体身份**：谁来承担叙事角色，以及该身份在所有层的出现（见上）。
2. **产品 / 品牌**：产品真相、用法、道具、UI、Logo、配色、证据、优惠、CTA。
3. **脚本 / 语言 / CTA**：话语意义、口播节奏、上屏文字、演示，以及新台词带来的时间关系。
4. **平台 / 时长 / 画幅**：哪些故事功能保留、压缩、扩展，哪些需要重新构图（横转竖、长改短）。
5. **视觉 / 调性风格**：统一的美术、字幕、花字、MG、特效、声音风格，但不抹掉参考有用的结构。
6. **增加 / 删除系统**：删掉某个系统后，要把它原来承担的工作重新分配（例如删掉榜单，就用别的方式呈现"比较"），不留叙事空洞。
7. **多参考**：写明每个功能取自哪条，冲突在 TREATMENT 里裁决，不混成大杂烩。

## 四、典型改编场景

### "把主持人换成我 / 换成我的数字人"

- 用一张肖像/数字人身份卡确定**外观**；声音用语音合成另选或用指定音色（肖像不决定声音）。
- 保留参考的机位、眼神、榜单/图形留白空间、那种自信的气场。
- 原片里调侃主持人外貌/个人经历的梗，要看新选角是否成立，必要时重写这个梗，而不是硬搬。
- 肖像照片的背景、姿势可以让位给视频真正需要的镜头。

### "把产品换成我的产品"

- 保住"随意推荐—怀疑—满意演示"这条互动结构，换成新产品的真实卖点。
- 台词、动作、画面、CTA 都从新产品**真实能提供的东西**长出来（真实产品图/UI 建立外观，用户资料/确认建立功效主张）。
- 用画面证据回应质疑（"你要我每次手动记？"→ 现场演示一键完成）。
- 人与产品同时换时，想清楚"为什么是这个人推荐、对方怎么反应、相遇为什么有意思"。

### 换语言

- 不是逐字翻译：按目标语言的口播节奏重写，保留铺垫/笑点的**位置与功能**，秒数会变。
- 显示与发音分别处理（数字、字母缩写、品牌名、价格读法，见 04）。
- 字幕分组、强调方式按目标语言习惯重排（中文最小单位是字，英文是词）。

## 五、把生成当成普通生产

- 把**图片模型**当见闻广博的画家，**视频模型**当一支有演员的摄制组，**音频生成**当声音团队。
- "真实感"是一种审美方向（手机随手拍、自然光、纪实晃动、房间环境音），不是对素材来源的声明。正常任务就是"创作新片需要的媒体"。
- 外部参考只在"公共知识无法确定精确身份"时才必须：本人、私有/小众产品、专有界面、精确 Logo 或数据。一旦某张生成图/视频被采纳，它就成为后续镜头的**权威参考**。

## 六、三种生成关系（决定每个镜头怎么喂素材）

| 关系 | 何时用 | 工具角色（适配层 00） |
| --- | --- | --- |
| **参考驱动生成**（图作为条件，不一定是首尾帧） | 身份、美术、构图、产品连续性重要——**克隆默认主力** | 图生视频 / 多模态视频 / 图生图 |
| **首尾帧约束** | 镜头的起点或终点画面本身就是设计好的连续动作端点 | 图生视频（首帧/尾帧） |
| **纯文本生成** | 镜头需要变化、无需精确视觉锚点（空镜、氛围、通用动作） | 文生视频 |

参考转移（给模型运动/节奏/表演气质，让它造新素材）与严格源编辑（直接改原片）是两种用法，都要明确告诉模型"这段参考负责什么"。

## 七、素材依赖保持浅而有用

- 直接产出**要用的成片素材**：主 A-roll 图、反打机位、B-roll 图、产品特写、分屏槽位。
- 第一张被采纳的主播图，往往就是主 A-roll 图；反打机位可以直接从它派生（描述新机位关系、视线、光线、转过去后自然变化的东西）。
- 独立的身份资产图（如固定数字人多角度母版、固定场景图）在确有需要时才做。
- **避免**生成一串"只为喂下一张而存在"的中间图。一个镜头超模型时长要拆时，各段复用同一批已采纳锚点，除非切点本身就是设计好的连续帧。
- 生成失败时，先改负责该问题的提示词/参考关系/镜头设计，再考虑换方案；创意答案本身错了才回 TREATMENT。

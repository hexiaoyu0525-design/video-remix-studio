# 00 · 工具与平台适配层（唯一写具体工具名的地方）

本技能是**导演方法论**，与具体生成平台无关。SKILL.md 与 references 01–07 里只提"角色"（文生图、图生视频、配音、剪辑……），**具体工具名只允许出现在这份适配层**。

换 agent / 换视频平台时，**只改这一份文件**，方法论不动。

## 一、工具角色清单（跨平台抽象）

| 角色 | 职责 | 何时用 |
| --- | --- | --- |
| 下载工具 | 把视频链接（抖音/B站/快手/YouTube 等）保存为本地文件 | 阶段 2 拿素材 |
| 转写工具 | 音视频转字幕/ASR，**词级时间戳**（中文平台显式指定 zh） | 阶段 2 建立 transcript |
| 媒资工具 | 探测时长/分辨率/帧率/音轨；按时间码抽帧、切片、网格 | 阶段 2 拆参考 |
| 文生图 | 从文字生成图片 | 阶段 5 身份锚点图、空镜静帧 |
| 图生图 | 以图为基础派生/重绘/多视角，保持身份 | 阶段 5 反打机位、换装换场景 |
| 文生视频 | 文字生成视频，无固定视觉锚点 | 阶段 5 空镜/氛围/通用动作 |
| 图生视频 | 以参考图/首尾帧驱动视频 | **阶段 5 克隆主力**（身份锚点驱动表演） |
| 多模态视频 | 视频+图+音频融合参考生成 | 阶段 5 多素材、严格参考转移 |
| 视频编辑 | 对已有视频做内容级修改（换人/物/背景/风格） | 阶段 5 改单条 |
| 配音合成 | 文字转语音，按角色音色 | 阶段 5 旁白/统一配音 |
| 剪辑工具 | 拼接/转场/裁切/调速/滤镜/运镜/分屏 | 阶段 6 确定性组装 |
| 字幕工具 | 字幕文件压制进画面 | 阶段 6 标准字幕条 |
| 混音工具 | 人声+BGM+音效混合、淡入淡出、音量 | 阶段 6 声音 |
| 专业编辑器 | 花字、头部追踪、逐字卡拉OK、逐帧 MG | 阶段 6 精细动效（人工后期） |

## 二、豆包环境适配（当前默认）

你在豆包对话里使用本技能时，按此映射调用：

| 角色 | 豆包环境实现 |
| --- | --- |
| 下载工具 | `doubao-video-extract` 技能 |
| 转写工具 | `analyze_audio`（词级时间；中文显式指定 zh） |
| 媒资工具 | `byted-mediakit-video`（探测/抽帧/切片/网格/OCR） |
| 文生图 | `image_gen`（Seedream 5.0） |
| 图生图 | `image_edit`（Seedream 5.0，多图参考） |
| 文生视频 | `text_to_video`（Seedance） |
| 图生视频 | `image_to_video`（Seedance） |
| 多模态视频 | `media_to_video`（Seedance） |
| 视频编辑 | `video_edit`（Seedance） |
| 配音合成 | `text_to_audio_plus`（1–120 秒） |
| 剪辑工具 | `byted-mediakit-editing`（20 个工具：concat/stitch/trim/crop/rotate/flip/adjust-speed/adjust-volume/filter/camera-motion/extract-audio/mux-audio-video/mix-audio/fade 等） |
| 字幕工具 | `byted-mediakit-editing` 的 add-subtitle-to-video |
| 混音工具 | `byted-mediakit-editing` 的 mix-audio / fade-audio / fade-video-audio |
| 专业编辑器 | 剪映专业版（jianying-editor）或即梦画布 |

### 豆包环境下的模型口径

- **图**：Seedream 5.0（生图/图生图）。
- **视频**：Seedance 2.0 / 2.0 fast / mini 单条 4–15 秒；Seedance 2.5 单条 4–30 秒（会员模型，耗更多额度）。默认 2.0 fast，按 15 秒内分段；用户明确要求单条 16–30 秒才上 2.5。
- **比例**：竖屏短视频默认 9:16，横版讲解/TVC 默认 16:9，商品卡可 1:1/3:4。
- **单条镜头生成规范**：进入阶段 5 生成视频时，遵循 `doubao-creative-video` 的五段式提示词、分镜、"生成前确认"与台词密度规则（本技能只补充克隆特有的参考图职责/身份锚点/依赖链，不重复它的规则）。
- **转写**：`analyze_audio` 中文要显式指定 zh，词级时间戳。
- **真人脸边界**：含真人脸的参考图/视频做换脸/克隆真人主持，豆包视频模型网关大概率拒绝且有合规风险；默认用 AI 数字人/自建模特，或仅在有明确授权时尝试并如实报告失败。AI 自建模特（非真人）不受限。

## 三、适配到其他平台（换环境时只改这里）

拿到另一套 agent/平台时，按**角色**对号入座，不要按豆包工具名找：

1. 通读本技能 SKILL.md 与 01–07，只认"角色"不认工具名。
2. 在平台能力清单里为每个角色选一个实现，填进下面表格。
3. 有平台缺角色时（例如没有多模态视频），用**流程降级**：该用多模态参考的镜头改用"图生视频 + 剪辑拼接"或"文生视频 + 后期叠加"，并在给用户的素材清单里注明降级。
4. 有平台加角色时（例如支持语音克隆），替换对应角色的职责描述，不影响方法论。

## 四、本技能自己的运行时约束（与平台无关）

- 技能不含逐帧渲染器/时间线引擎，复杂花字追踪、逐字卡拉OK、数据图表逐帧动画、HTML 级动效属于"专业编辑器"角色。
- 单条视频受平台模型时长上限约束，长片靠分段生成 + 剪辑拼接。
- 数字/价格/年份的显示与发音分别写（见 04）；Logo/品牌/真人脸/数据/功效宣称必须有用户素材或授权（见 05、06 合规）。

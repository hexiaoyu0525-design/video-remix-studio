# 05 · 素材生产：身份锚点 → 图 → 视频 → 配音

这一阶段把 SCRIPT 变成可用素材。**顺序固定：先建身份锚点图，再以它为参考批量生成视频，最后配音/合成。** 依赖保持浅，避免一长串中间图。

生成单条镜头的提示词结构、分镜、台词密度、黄金三秒、生成前确认，遵循**适配层中当前环境的视频生成规范**（豆包环境 = `doubao-creative-video`）；本篇只补充"克隆改编特有"的部分。本篇提到的所有"工具角色"（文生图、图生图、图生视频、配音等）以 [00-tool-adapters.md](00-tool-adapters.md) 的当前环境映射为准，**不要在本篇写死具体工具名**。

## 一、生产顺序（依赖图）

```
1. 身份锚点图（人物场景图，文生图）
     ├─ 2a. 主播多视角（反打/侧面/半身）→ 图生图，以锚点图为参考
     ├─ 2b. 产品/场景锚点图（如需要）→ 文生图/图生图
     └─ 3. 各段视频（以锚点图为参考条件）→ 图生视频 / 多模态视频
4. 空镜/B-roll（文生视频 或 独立静帧）
5. 配音（配音合成，按角色）
6. 验收通过的素材进入合成（06）
```

- **第一张被采纳的主播图通常就是主 A-roll 图**。它要预留好后期构图（见下）。
- 反打、第二机位、不同景别，都从已采纳锚点图派生：用图生图明确"这张图负责什么不变（身份/场景），新机位改变什么"。
- 不为"喂下一张"而造图；每个分镜片段复用同一批锚点。
- 多图/多参考输入时，提示词里**明确点名"图1/图2/图3"各自负责什么**（实测比模糊指代可控），传入顺序与编号一致。

## 二、图片导演：四张幕布，各负其责

给图片模型的描述按四个职责组织（不是逐项填空，参考已锁定事实的部分可省略）：

1. **拍摄质感（Capture）**：这是什么摄影语言。手机随手拍、自然光、纪实感、竖屏自拍视角；还是产品棚拍、电影感。"真实"是审美方向，要写清。
2. **人物（Person）**：这是谁、为什么值得看、哪几个外观特征让他/她具体而非路人。
3. **镜头（Shot）**：在做什么、对谁说话、机位如何框住脸/身体/手/留白。
4. **场景（Setting）**：地点、几件讲述物件、刻意的调色板。

### 主播选角七问（确定高价值决策，其余交给模型）

1. 这是什么类型的拍摄画面？
2. 人物是谁，吸引力的**类型与强度**（惊人的美/亲和力/喜感/专业可信）？
3. 哪几个外观锚点让他可识别（发型、眼神、一件标志性服装/配饰）？
4. 下一个视频镜头能延续的"可持续状态"是什么（对镜说话、空手做手势）？
5. 机位如何框住这次相遇（脸、身体、视线、给图形/榜单的留白）？
6. 什么可见关系让人物与场景属于彼此？
7. 哪组颜色给画面定调？

### 选角要点

- 写清实际年龄与身份；"美/帅"要给**强度+类型**（如"有顶级演员气场的、醒目的美"），比单写"好看"有效。
- 半身主播给"肩宽、头肩比例好"的结构锚点，避免头大肩窄。
- 只需几个决定性笔触，其余让模型补全，不必堆砌特征清单。
- 参考图（用户肖像/数字人身份卡/产品图）能锁定的事实就交给参考，提示词只描述这次相遇与新视角。

### 静态姿势（可复用的主播图）

- 对镜说话 + 空手做手势是**可持续活动**，不是僵死摆拍；脸正对镜头、不歪头、不转头，给后续表演稳定起点。
- 对话/采访类要让人物之间有视线关系（看向对方），脸从所需机位可读。
- 大笑/震惊等强表情只在那个瞬间就是镜头主题时才用。

### 为后期构图而拍

- 预判花字/榜单/产品卡/字幕的位置，把脸和身体放在画面相应侧，留出干净区域；描述里只写该画的物理场景，别把后期图形画进去。
- 需要后期抠像/分屏，就预留身体完整度与背景；用生成图做透明抠像不可靠，需要抠像时用当前环境的媒资/专业能力（豆包环境见 byted-mediakit-video）。

### 场景

- 场景要承载一个社会世界：命名可识别的地点 + 几件会讲故事的物件（咖啡店座位和半份甜点、堆满样衣的工作台、货架）。
- 给刻意调色板，颜色通过建筑/服装/道具/植物呈现，不是一面纯色墙。
- 时间、天气、特殊光线只在剧情需要时写。

## 三、视频导演：先导演"态度"，再写动作

### 先写表演理由，再写落点细节

- 第一句定**这段表演的关系**：说话者如何看待话题、与听者什么关系（向朋友热情安利、带着怀疑求证、亲昵吐槽太贵、认真做科普）。
- 再给几个决定性落点：挑眉、摊手、点头、身体前倾；细节只在能澄清判断、揭示反应、保持关键物理关系时才加。
- 克制是有目的的：一个 deliberate 的小反应比不停乱动更有说服力。让呼吸、眨眼、小动作提供日常感。
- 同一张脸、同一个声音可以在不同段落表达不同态度；身份不变，情绪随内容走。

### 用具体可见的语言，禁用比喻

- 模型会把比喻画成字面物体："让想法有形"可能真的画出一个漂浮的物体。要写**可见的眼神、手势、移动、机位、动作**。
- 说话主体与可见动作职责分开：台词交给口播，动作描述人物对台词的反应，别让模型用手势去比划台词里的数字或抽象概念（数量交给字幕/花字）。
- 自然强调的手势比让手比出精确数字可靠。

### 每个输入职责明确（喂素材时讲清）

| 输入 | 负责 |
| --- | --- |
| 人物+场景参考图 | 外观、场景、构图、要保持的物理状态 |
| 产品/界面参考图 | 必须连续或精确的可见事实 |
| 源视频片段 | 要保留的表演节奏、运动轨迹、接触、机位关系 |
| 声音参考 | 音色身份（模型支持时） |
| 台词 | 确切的话、读法、说话轮次 |
| 段落导演 | 态度、语气、注意力、肢体互动、机位、有动机的剪切 |

### 只有连续时间行为关键时才用源视频

- 静帧能定身份/场景/构图，文字能定动作，就不必喂视频；只有**表演节奏、运动路径、接触、机位关系、特效演化**这类"逐字静帧会丢"的信息，才用多模态视频喂源片段。
- 用法分清：**参考转移**（借它的时间属性造新素材）vs **严格源编辑**（直接改这段原片，用视频编辑工具，说明改什么、保留什么）。
- 选片段要含有用动作及其预备/收尾；看清整段，不只看首帧。

### 剪辑与镜头

- 口播社媒偏好**停顿处修剪的跳剪**（jump cut），保持紧迫感，像博主自己剪的；机位稳定、表情生动、勤剪。
- 一条生成视频可以包含多个镜头、多轮对话、分屏；**Segment ≠ 镜头**。几条片段也可以复用同一锚点图。
- 超时长按可表演段落拆，物理连续需要时用前段真实尾帧作下一段输入；做不到就明确用跳剪/转场，不假装连续。

### 时长与模型

- 先按 04 估时，再对照适配层当前平台模型时长选条数（豆包环境：2.0 系 4–15 秒、2.5 4–30 秒会员，默认 2.0 fast）。
- 参考源片的秒数只解释节奏，不自动成为新片时长。

## 四、声音选角（配音合成）

像选演员一样选声音，先想象"一个值得听下去的声音"：

1. 谁在说、对谁说、什么让这个声音对该角色有吸引力。
2. 高级感官 + 决定性特质：音高、重量、亮度、柔软度、颗粒感（"略带沙哑"是具体纹理，用在合适时）。
3. 压成**一段**生动描述：可识别的声音角色 + 吸引人的音质 + 有特点的对人说话方式。
   - 示例：年轻女性，清亮甜美的高音、轻盈顺滑，美式口语，像朋友兴奋地给你安利好物；问句带着好奇上扬，回答时声音里有笑意。
   - 示例：成熟男性，圆润低沉的中音、放松的英式英语，像在桌边与人一起斟酌想法；措辞有分寸、重点词有信念感。
4. 样本句用表演语言、自然短句，让音色有展示空间；同角色跨段落复用同一音色，情绪随段落变。
- 视频模型能自带口型说话时，台词走视频生成；需要独立旁白/统一配音/重配时，用配音合成单独生成，再合成。
- 一个角色一条配音，跨段保持一致；显示与发音分离的读法（04）要写进配音文本。

## 五、素材清单（shots/ 里逐条登记）

每条镜头一行，生成前给用户确认（工具列写**角色 + 当前平台模型**，不要写平台内部代号）：

```
| 镜头 | 类型 | 工具/模型 | 输入参考及职责 | 台词段 | 时长 | 比例 | 产出 | 状态 |
| SH01 | 主播A-roll | 文生图（当前平台） | 数字人身份卡=图1 | - | 静帧 | 9:16 | 主播锚点图 | 待确认 |
| SH02 | 开场说话 | 图生视频（当前平台默认档） | 图1=SH01锚点 | S01 | 6s | 9:16 | 开场片段 | 待生成 |
```

## 六、生成前确认与合规

- 每批生成前，向用户出示模型、时长、比例、数量、参考图职责、预计消耗，明确同意后再生成（遵循适配层中当前环境的视频生成确认流程）。
- **真人脸**：用真人肖像做换脸/克隆真人主持，多数视频模型网关大概率拒绝且有合规风险；默认用 AI 数字人/已授权形象，失败如实报告。AI 自建模特不受影响。
- **品牌/Logo/印花/真人脸**：**参考层无红线**——一切图皆可看、可学、可拆（学廓形/手法/质感/氛围/构图）。**技术提示**：品牌 Logo/老花/注册印花慎喂垫图（模型会原样复现标志、画进画面后难剥离）；当代品牌/在世设计师作品参考随便用，**公开交付**（参赛/商用/公开发布）须实质转化到不可识别同源；练习/内部全 🟢。合规只看交付。（口径与 `fashion-studio` copyright-compliance 一致）
- 私有产品/界面/数据必须有用户素材；公共知识能确定的才让模型直接画。
- 数字/价格/功效不编造，来源标注清楚。

## 七、验收与返工

- 每条素材对照它承担的职责验收：身份是否一致、动作是否表达了态度、台词是否在、构图是否给后期留了位、产品事实是否对。
- 问题归属：身份/构图/产品错 → 改参考图关系或重新出锚点；表演/动作错 → 改段落导演与提示词；台词错 → 改 SCRIPT 重配；创意本身错 → 回 TREATMENT。
- 已采纳的素材登记为权威，后续复用，不重复花额度。
